# csv

Airline dataset for passenger satisfaction with a small data-mining workflow.

## Files

- `data/airline_passenger_satisfaction.csv`: dataset file
- `datamining.py`: Python script that runs basic data-mining analysis

## Run

```bash
python datamining.py
```

The script prints:
- overall satisfaction rate
- satisfaction rate by class
- arrival-delay comparison between satisfied vs not satisfied passengers
- most common travel type among satisfied passengers
